# Gear Profile Calculation Summary

This summary explains the logic in `profiles/involute_profile.py` and how the involute gear profile is generated.

## 1. Purpose of the script

The script creates a simplified involute gear profile from three main inputs:

- `m` = module (mm)
- `z` = number of teeth
- `pressure_angle` = pressure angle in degrees

It calculates the gear geometry, generates the involute curve for each tooth, plots the profile, and saves the image to `figures/gear_profile.png`.

---

## 2. Inputs and meaning

The program starts with:

```python
m = 12
z = 18
pressure_angle = 20
```

These values define a gear size and tooth geometry.

The key idea is:

- the pitch circle is the reference circle used for gear meshing
- the involute profile is created from the base circle
- the pressure angle controls how the teeth lean and mesh

---

## 3. Core gear geometry formulas

### Pitch circle radius

```python
r_p = m * z / 2
```

This is the radius of the pitch circle.

### Pressure angle in radians

```python
phi = np.radians(pressure_angle)
```

The script converts the pressure angle from degrees to radians because Python math functions expect radians.

### Base circle radius

```python
r_b = r_p * math.cos(phi)
```

The base circle is important because the involute is generated from it. The involute is the path traced by a point on a taut string unwinding from the base circle.

### Addendum circle radius

```python
r_a = r_p + m
```

This is the outside radius of the gear tooth.

### Root circle radius

```python
r_r = r_p - (1.25 * m)
```

This is the lower limit of the tooth profile, near the root.

---

## 4. Derived dimensions in the report

The script also computes and prints:

```python
pitch diameter = 2 * r_p
base diameter = 2 * r_b
addendum diameter = 2 * r_a
root diameter = 2 * r_r
```

It also calculates:

```python
circular pitch = π * m
tooth thickness at pitch = π * m / 2
```

These values help describe the spacing and tooth width of the gear.

---

## 5. Involute mathematics

The involute curve is parameterized by a variable `t`.

The script uses:

```python
t_max = math.sqrt((r_a / r_b) ** 2 - 1)
t = np.linspace(0, t_max, 100)
```

This sets the valid range of the involute from the base circle up to the outer tooth tip.

The involute coordinates are generated using:

```python
x_inv = r_b * (np.cos(t) + (t * np.sin(t)))
y_inv = r_b * (np.sin(t) - (t * np.cos(t)))
```

This is the standard involute-of-a-circle equation.

Where:

- `x_inv` and `y_inv` are the coordinates of the involute curve
- `r_b` is the base circle radius
- `t` is the involute parameter

This is the curve that forms the tooth flank.

---

## 6. Tooth offset and rotation

For gear teeth, the involute profile must be rotated into the correct tooth position.

The script computes:

```python
inv_phi = np.tan(phi) - phi
offset = (np.pi / (2 * z)) - inv_phi
```

This is a useful gear-related relation. It helps center each tooth around the correct angular position.

Then for each tooth:

```python
teeth_angle = i * 2 * np.pi / z
angle_right = teeth_angle + offset
angle_left = teeth_angle - offset
```

Each tooth is rotated to a different angular location around the gear. The right and left flanks are then generated by rotating the same involute profile around the gear center.

---

## 7. Flow of the plotting logic

The program uses the following sequence:

### Step 1: Build the report

```python
report = generate_profile_report(m, z, pressure_angle)
```

This function calculates all the main geometry values and builds a formatted text report.

### Step 2: Compute the gear circle radii

```python
r_p = m * z / 2
r_b = r_p * math.cos(phi)
r_a = r_p + m
r_r = r_p - (1.25 * m)
```

These define the main gear circles.

### Step 3: Create base circle plots

The code creates circles for:

- pitch circle
- base circle
- addendum circle
- root circle

```python
angles = np.linspace(0, 2 * np.pi, 360)
```

This creates a full 360-degree angular array used to draw circles.

### Step 4: Generate the involute curve

```python
x_inv = r_b * (np.cos(t) + (t * np.sin(t)))
y_inv = r_b * (np.sin(t) - (t * np.cos(t)))
```

This defines the tooth flank curve.

### Step 5: Rotate each tooth around the gear

For every tooth index `i`:

```python
for i in range(z):
    teeth_angle = i * 2 * np.pi / z
    angle_right = teeth_angle + offset
    angle_left = teeth_angle - offset
```

Then it rotates the involute points using 2D rotation formulas:

```python
x_right = (x_inv * np.cos(angle_right)) - (y_inv * np.sin(angle_right))
y_right = (x_inv * np.sin(angle_right)) + (y_inv * np.cos(angle_right))
```

and

```python
x_left = (x_inv * np.cos(angle_left)) + (y_inv * np.sin(angle_left))
y_left = (x_inv * np.sin(angle_left)) - (y_inv * np.cos(angle_left))
```

These rotated points form the left and right flanks of each tooth.

### Step 6: Connect the tooth flanks to the root circle

The code finds the starting point of each involute and then draws a line from the involute near the base to the root circle.

```python
theta_right = np.arctan2(y_start_right, x_start_right)
```

This converts the start point into an angle so the script can compute the corresponding root-circle intersection.

Then:

```python
x_root_right = r_r * np.cos(theta_right)
y_root_right = r_r * np.sin(theta_right)
```

This finds the root position for each flank.

### Step 7: Draw the tooth boundaries

The script connects the right tip of one tooth to the left tip of the next tooth using straight lines:

```python
for i in range(z):
    x1, y1 = right_tips[i]
    x2, y2 = left_tips[(i + 1) % z]
    plt.plot([x1, x2], [y1, y2], color=involute_color, linewidth=2)
```

This closes the tooth shape between neighboring involute flanks.

### Step 8: Save and display the figure

```python
plt.savefig(save_path)
plt.show()
```

The resulting gear profile is saved as:

`figures/gear_profile.png`

## 8. Important geometric meaning

This script is not a full gear manufacturing model, but it captures the essential gear tooth geometry:

- pitch circle = center reference for gear mesh
- base circle = source of the involute curve
- addendum = tooth tip
- root = lower tooth region
- involute curve = tooth flank profile

The key engineering idea is that each tooth flank is generated as an involute of the base circle, which gives smooth meshing between gears.

## 9. Simple visual interpretation

Imagine a string unwinding from a base circle. The end of the string traces an involute curve.

That involute is used as the tooth flank because it provides:

- smooth contact between gear teeth
- consistent motion transfer
- good meshing behavior under pressure angle design
